## 标准化流程

### Step 1: 分析参考图

调用 GLM-4V-Flash 分析参考图，提取精确布局参数：

```python
q = ("精确测量这张参考图。图片高度是XX像素。\n"
     "1) 标题文字高度大约多少像素（占高度%）？\n"
     "2) 副标题文字高度大约多少像素（占高度%）？\n"
     "3) 底部文字高度大约多少像素？\n"
     "4) 标题底部到副标题顶部的间距大约多少像素？\n"
     "5) 右侧文字整体距离顶部多远（像素）？\n"
     "6) 左侧手环的上下左右边距百分比？\n"
     "7) 背景主色RGB值？\n"
     "回答格式：直接用数字，如'标题高度: 80px (5.6%)'")
```

### Step 2: 按比例换算

将参考图测量值按画布尺寸等比例换算：

```
参考图: 2134×1422 (3:2)
目标图: 1800×1200 (3:2)
缩放因子: 1200/1422 = 0.844
```

| 元素 | 参考图 | 目标图 (1800×1200) |
|------|--------|---------------------|
| 标题字号 | 380px (26.7%) | 320px (26.7%) |
| 副标题字号 | 120px (8.4%) | 100px (8.4%) |
| 底部文字 | 60px (4.2%) | 50px (4.2%) |
| 标题起始Y | 500px (35%) | 396px (33%) |
| 标题-副标题间距 | 200px (14%) | 72px (6%) |

### Step 3: 生成海报

运行 `python omo/gen_poster.py` 生成 `release_repo/cover.png`。

`gen_poster.py` 使用 Pillow 绘制，关键参数：
- 画布: 1800×1200 (3:2)
- 背景: 天蓝色渐变
- 左侧: 小米手环10皮肤 + 应用截图
- 右侧: 标题 + 副标题 + 功能文字

### Step 4: 云端质检

同时发送参考图和生成图给 GLM-4V-Flash，获取对比评价：

```python
q = ("看图A(参考图)和图B(腕上词典海报)。\n"
     "1) 标题大小是否一致？（评分1-10）\n"
     "2) 颜色氛围是否匹配？（评分1-10）\n"
     "3) 整体布局是否协调？（评分1-10）\n"
     "4) 给出2-3个具体改进建议\n"
     "要求：每个建议必须可操作，如'把XX字号从XX改成XX'")
```

### Step 5: 迭代优化

根据质检反馈修改 `gen_poster.py`，重复 Step 3-5 直到：

- 标题大小匹配度 ≥ 8/10
- 颜色氛围匹配度 ≥ 8/10  
- 布局协调度 ≥ 8/10
- 无负面视觉反馈

## 颜色调优指南

参考图颜色提取（通过 PIL 采样）：

```python
from PIL import Image
import collections
img = Image.open(path).convert('RGB')
# 全图采样
colors = [img.getpixel((x, y)) for x in range(0, w, 4) for y in range(0, h, 4)]
counter = collections.Counter(colors)
# 取前10个主色
for color, count in counter.most_common(10):
    print(f'RGB{color}  - {count} px')
```

典型参考图(学习盒子)主色：`RGB(118, 204, 255)` 天蓝、`RGB(255,255,255)` 白。

## 质检打分标准

| 维度 | 10分标准 |
|------|---------|
| 标题大小 | 与参考图偏差 < 5% |
| 颜色氛围 | 主色调差异肉眼不可辨 |
| 布局比例 | 左右分割、上下边距与参考一致 |
| 文字层次 | 字号递进关系匹配参考图 |
| 整体协调 | 无拥挤/空洞感，留白恰当 |

#### 英汉词典
- 英文索引分短/中/长三档，中文索引也分短/中/长
- 自定义输入法支持 QWERTY、T9、拼音、手写

#### So词典-英汉版

- 查词统计功能
- 激活码验证

- 定位为单词学习工具而非词典

- 激活码验证
- 无中文搜索、无模糊搜索、无变形

#### 腕上词典（本项目）
- 紧凑前缀压缩英文索引（26 文件）
- 中文查词（汉字+词组双向）
- 编辑距离模糊搜索（≤2）
- 变形/反查索引

- 纯离线免费

## 四、索引原理对比

### 4.1 英汉词典 — 分片映射索引

**核心思路**：构建期将 50,910 词条分到 100 个 dict 分片，再为每个分片建立关键词 → 分片号的索引。

**索引结构**（4 类 x 4 档次）：

```
common/index/
├── index_en_0..3.txt          # 英文索引（4 分片）
├── index_en_short_0..3.txt    # 英文短词索引
├── index_en_long_0..3.txt     # 英文长词索引
├── index_zh_short_0..7.txt    # 中文短词索引（8 分片）
├── index_zh_medium_0..7.txt   # 中文中词索引
└── index_zh_long_0..7.txt     # 中文长词索引
```

**行格式**：
```
<dict分片号>|<候选关键词列表>
56|... apple ... cider ...
```

**搜索流程**：
1. 根据输入语言和词长选择索引文件（短/中/长）
2. 在索引中搜索关键词 → 得到候选 dict 分片号
3. 只读取候选分片（如 `dict_56.txt`）
4. 对候选行做精确/前缀/模糊过滤

**优点**：按词长分索引可快速缩小搜索范围
**缺点**：索引文件体积较大（共 36 文件 ~3.30 MB）；需要维护多套索引

**词条数据**：100 个 `dict_00.txt` ~ `dict_99.txt`，每行 `word /'ipa'/	释义	变形标签`

### 4.2 So词典-英汉版 — 7 种索引的多维检索

**核心思路**：为不同搜索场景构建专用索引，覆盖精确/前缀/全文/模糊/中文搜索。

**7 种索引类型**：

| 索引 | 用途 | 分片方式 | 说明 |
|------|------|----------|------|
| `exact-surface` | 英文精确匹配 | Unicode 码点分片 (u0073= s) | 单字符分片，每个文件包含该字符开头的所有词 |
| `exact-zh` | 中文精确匹配 | Unicode 码点分片 (u4e= 一) | 按中文字首字分片 |
| `fast-priority-prefix` | 英文前缀补全 + 中文前缀 | surface/zh 两个子目录 | 用于快速补全建议 |
| `full-surface-sorted` | 英文全文排序 | Unicode 码点分片 | 所有词按字母序排列的文件 |
| `full-zh-sorted` | 中文全文排序 | 按首字分片 | 中文词组按拼音/笔画序排列 |
| `fuzzy-surface-ngram` | 英文模糊搜索 | ngram 分片 | 基于 n-gram 的模糊匹配索引 |
| `fuzzy-zh-ngram` | 中文模糊搜索 | ngram 分片 | 中文 n-gram 模糊索引 |

**索引行格式**（以 exact-surface 为例）：
```
word1	释义1
word2	释义2
```

**搜索流程推断**：
1. 输入查询词 → 计算 Unicode 码点 → 定位 exact-surface 分片
2. 精确匹配成功 → 直接返回释义
3. 精确失败 → 尝试 prefix 或 ngram 模糊索引
4. 中文搜索走 exact-zh / full-zh-sorted / fuzzy-zh-ngram

**词条数据**：`assets/dictionary/entries/` 分片，`assets/dictionary/summaries/` 摘要信息

**优点**：搜索精度高，每种场景有专用索引
**缺点**：索引冗余大，总字典体积 ~10MB+；需维护 7 套索引一致性

### 4.3 腕词汇 — 平面分片 + 词汇书

**核心思路**：最简单的方案——将所有词条平铺到 208 个 part 文件，不建索引，搜索时扫描。

**索引结构**：无独立索引文件。

**词条数据**：208 个 `part000.txt` ~ `part207.txt`，每行一个词条。

**词汇书**：`common/wordsbooks/` 下按考试分类：
- `primary/primary.txt` — 小学词汇
- `junior/7-1.txt`, `7-2.txt`, `8-1.txt`, `8-2.txt`, `9.txt` — 初中词汇
- `senior/3.txt` — 高中词汇
- `ielts/ielts_1..8.txt` — 雅思词汇
- `toefl/toefl_1..8.txt` — 托福词汇

**搜索流程推断**：
1. 输入单词
2. 遍历 part 文件或词汇书找到匹配
3. 返回释义

**优点**：实现简单，词汇书系统适合背词场景
**缺点**：无索引 = 搜索慢（线性扫描 100,000 词）；无模糊搜索；无中文搜索

### 4.4 腕上词典 — 紧凑前缀压缩索引

**核心思路**：对英文词条排序后进行**前缀压缩**（prefixLen+suffix），大幅减少存储空间；中文用 Unicode bucket + delta-base36 编码。

**英文索引**（26 文件）：`words/word_a.txt` ~ `word_z.txt`
```
<prefixLen,suffix>\t<entryId(base36)>\t<tagCode(hex)>
示例: 0,a  0	3       → "a"
      1,bandon  1	de  → "abandon"（重用一个字符 "a"）
      7,ed  2	40      → "abandoned"
```

**中文索引**（64 × 2 文件）：
- `zh_index/zh_00~3f.txt` — 汉字索引，`汉字\t<delta-base36-ids>`
- `cn_index/cn_00~3f.txt` — 词组索引，同上加前缀压缩

**词条数据**（30 文件）：`entries/entry_00.txt` ~ `entry_29.txt`
```
word\tphonetic\ttranslation\ttag
```

**搜索流程**：
1. 英文：首字母分片 → 读取 word_{letter}.txt → 解码前缀压缩 → startsWith 过滤 → 读取 entry 分片补全
2. 中文：ord(首字) % 64 → 读取 cn_{bucket}.txt → delta-base36 解码 → 精确/前缀匹配 → 补全 entry
3. 模糊：编辑距离 ≤2，扫描 ≤4000 词

**优点**：存储效率高（4.4 MB vs 10MB+）；搜索路径短（2 次文件读取）；前缀压缩减少 60%+ 索引体积
**缺点**：词条数最少（14,942）；中文索引 cn_index 体积偏大（47%）

## 七、各自的优劣总结

### 英汉词典
**优势**：词条量大（50k）；短/中/长索引分档搜索高效；变形索引完善（119k 行）
**劣势**：索引体积大（3.3 MB）；不支持下载词包；仅适配 212px 固定宽度；已编译为 jsc 不可直接修改

### So词典-英汉版
**优势**：词条量最大（100k+）；7 种索引覆盖所有搜索场景；多设备适配（Band 9/Pro/Wide）；支持下载词包扩展；日文假名键盘
**劣势**：索引冗余极大（每种索引一套文件）；架构最复杂；需要激活码验证；英文搜索主要面向日英/中英

### 腕词汇
**优势**：词条量大（100k）；词汇书系统设计精巧（按考试分类）；背词模式完整（学习+测试）；实现简单
**劣势**：无索引导致搜索性能差；无中文搜索；无模糊搜索；无变形；输入法仅为字母表盘

### 腕上词典（本项目）
**优势**：存储效率高（前缀压缩 + delta-base36）；中文搜索能力完善（汉字+词组双向）；模糊搜索 + 变形反查；考试标签丰富（8 级）；纯离线免费
**劣势**：词条数最少（15k）；中文索引 cn_index 体积占比异常高（47%）；需更多词条扩展；无词汇书/背词功能

# Vela QuickApp Project — Mandatory Skill Loading

This is a **Xiaomi Vela QuickApp** project (腕上词典 / Wrist Dictionary).

## Mandatory Rule

**Before any work involving:**
- `.ux` files (editing, reading, creating)
- `manifest.json` or app config
- Vela components, APIs, or framework features
- Build/deploy with `aiot-toolkit`
- ADB deployment or emulator testing

**ALWAYS execute:**
```
skill(name="vela-dev")
```
This loads the full Vela QuickApp development skill with official documentation, component reference, API docs, and best practices.

## Also Relevant Skills

| Skill | When |
|-------|------|
| `vela-dev` | **Always** — mandatory for any Vela work |
| `ui-ux-pro-max` | UI/UX design for watch screens |
| `ui-ux-design` | Design patterns for wearable UIs |
| `JavaScript` | Writing robust JS for .ux scripts |

## Exception

If the task is **pure code reading/explanation only** (no editing, no building, no debugging), the skill is not required but still recommended for context.
